시작 방법

① 메인 메뉴 → 훈련 시작
② 드론 기종 · 지형 · 카메라 시점 · 날씨 · 난이도 선택
③ 비행 개시 → 로딩 완료 후 작전 브리핑 팝업 확인
④ ▶ 작전 개시 버튼 클릭 → 비행 시작

💡 미션 모드는 시작 시 목표·조작법·경고가 담긴 작전 브리핑이 자동으로 표시됩니다.

단계별 첫 비행

1. 이륙: Space 1~2초 → 스로틀 50%↑ → 고도 20m 확보

2. 호버링: 초급 모드에서 키를 떼면 자동 안정화

3. 이동: W/S 전후진, A/D 좌우. 짧게 눌렀다 떼는 연습 권장

4. 회전: Q/E로 기수 방향 전환 → W키로 그 방향으로 전진

5. 착륙: X키로 서서히 하강 — 고도 5m 이하 시 HUD 경고

💡 3인칭 모드: 마우스 좌클릭 드래그로 카메라 자유 조작 — 손 떼면 드론 뒤로 자동 복귀
💡 FPV 모드: V키로 언제든지 3인칭 ↔ FPV 전환 가능

3인칭 추적 카메라

드론 뒤에서 따라가는 시점입니다. 드론의 위치·자세·주변 지형을 한눈에 파악할 수 있어 초보자에게 적합합니다.

마우스 좌클릭을 누른 채 드래그하면 카메라를 자유롭게 조작할 수 있습니다. 버튼을 떼면 카메라가 드론 뒤쪽으로 부드럽게 자동 복귀합니다.

방향키 ↑↓←→으로도 카메라 각도를 조절할 수 있습니다.

💡 초보자는 3인칭 카메라로 시작해 주변 지형과 드론 상태를 익히는 것을 권장합니다.

1인칭 FPV (First Person View)

드론에 탑재된 전방 카메라 시점으로, 실제 드론 조종사가 FPV 고글을 통해 보는 것과 동일한 경험을 제공합니다.

드론이 롤(좌우 기울기)할 때 화면도 함께 기울어져 현실감을 줍니다.

FPV 모드에서는 화면 상단에 ● REC FPV CAM 표시와 비네트 효과가 적용됩니다.

💡 V키로 비행 중 언제든지 시점 전환이 가능합니다. 타격 미션은 FPV 모드에서 Lock-on이 더 직관적입니다.

미션 공통 — 작전 브리핑

미션 모드로 비행 시작 시 작전 브리핑 팝업이 자동으로 표시됩니다. 팝업에는 미션명·목표·제한시간·조작 가이드가 포함됩니다.

▶ 작전 개시 버튼을 눌러야 비행이 시작됩니다. 브리핑을 꼭 읽고 시작하세요.

💡 화면 상단 중앙에 ⏱ 남은 시간이 항상 표시됩니다. 60초 이하 시 빨간색으로 변합니다.

🔵 정찰 미션 수행법

정찰 드론으로 적 진지·오염 구역 등을 탐색하고 영상 데이터를 수집하는 임무입니다.

단계내용
① 방향 확인화면 하단 방향 화살표 HUD로 목표 방향·거리 확인
② 접근목표 지점 100m 이내 접근 + 고도 80m 이하 유지
③ 스캔조건 충족 시 화면 하단에 스캔 진행바 표시 — 3초 유지
④ 완료스캔 완료 → 자동으로 다음 목표로 화살표 업데이트
⑤ 귀환마지막 목표는 출발 지점(기지) 복귀 — 기지 36m 이내 접근
💡 방향 화살표가 ✅ 스캔 중...으로 바뀌면 그 위치에서 3초 유지하세요.

🔴 타격 미션 수행법

미사일로 적 차량·거점을 정밀 타격하는 임무입니다. 미사일은 MQ-9 리퍼가 6발, 그 외 드론은 4발을 탑재합니다(공격 드론 권장).

단계내용
① 방향 확인화면 하단 빨간 화살표 HUD로 목표 방향·거리 확인
② 접근목표 800m 이내 접근 → Lock-on 가능 범위 진입
③ Lock-on화면 중앙 근처에 목표가 들어오면 🔴 LOCK 표시 자동 활성
④ 발사F키 발사 → 미사일이 목표까지 자동 유도
⑤ 확인미사일 명중 시 폭발 효과 + 목표 소멸 확인
💡 화면 하단 공격 가이드 바에 현재 Lock-on 상태·목표 거리·잔여 미사일이 실시간 표시됩니다.
⚠ Lock-on 없이도 발사 가능하지만 비유도(직진) 발사입니다. 명중률이 크게 낮아집니다.
⚠ 미사일은 제한된 수량입니다. 모든 목표를 파괴할 수 있도록 신중하게 사용하세요.

🟢 방어 미션 수행법

기지로 접근하는 적 드론을 격추·포획하는 임무입니다. 드론 종류에 따라 방어 방식이 다릅니다.

드론방어 방식방법
🛡 NET-1 그물포획근접 자동 포획적 드론 22m 이내 접근 → 자동 그물 발사·포획
⚡ INT-K 요격드론유도 미사일적 드론 1200m 이내 → 🔴 LOCK → F키 발사

미니맵의 적색 점으로 접근 방향 실시간 파악 → 진로 차단이 핵심 전략입니다.

⚠ 적 드론 3기가 기지에 도달하면 미션 실패. 10기 격추/포획 시 미션 성공.
💡 적은 7초마다 랜덤 방향에서 스폰됩니다. 미니맵을 주시하며 선제 요격하세요.

⑤ Lock-on 유도 무기 시스템

타격·방어 미션에서 사용하는 실전 방식의 Fire-and-Forget 유도 미사일입니다.

단계내용
탐색 (SEARCH)화면에 흰색 박스 — 목표 시야 내 탐색 중
추적 (TRACK)노란색 박스 — 목표 범위 근접, 준비 상태
잠금 (LOCK)빨간색 박스 — 사거리 이내, F키 발사 가능
유도 비행발사 후 미사일이 목표 좌표까지 자동 조향
명중/폭발명중 시 폭발 이펙트 + 조명 플래시 효과
💡 잠금 범위: 타격 목표 800m / INT-K 요격기 1200m / NET-1 그물 22m
