③ 비행 물리 시뮬레이션

  • 기종별 최고속도·최대고도 — 드론 데이터 기반 물리 적용
  • 4단계 난이도 — 초급(자동 안정화) / 중급 / 고급(실전 물리) / 전문가(완전 수동)
  • 중력·항력 — 스로틀 감소 시 중력에 의한 자연 하강
  • 바람 영향 — 풍향/풍속이 드론 궤도에 실시간 영향
  • 난기류 — 설정값에 따른 랜덤 흔들림
  • 배터리 소모 — 비행 시간 + 스로틀에 따른 소모. 방전 시 강제 착륙
  • 지형 충돌 감지 — 매 물리 프레임 레이캐스팅으로 드론 위치의 지형 높이 측정. 드론이 지형면 0.8m 이하 접근 시 폭발 이펙트 + "지형 충돌 — 드론 추락" 임무 실패 처리
  • 지형 충돌 바닥 보정 — 완만한 하강 시에는 드론 Y를 terrainH+0.8m로 클램프하여 지형을 관통하지 않음
  • 지면 충돌 방지 — 비임무 모드에서 최저 고도 0.5m 자동 제한

⑤ 기종별 전용 3D 모델 (7종 빌더)

  • MQ-9 리퍼 (bMQ9) — 6.6m 동체, V형 미익, AGM-114 헬파이어 ×4 파일런, SATCOM 돔, EO/IR 터렛, 3엽 후방 프로펠러, 항법등
